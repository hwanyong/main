## 📖 프로젝트 소개

**agbridge (Antigravity Bridge Daemon Client)**는 macOS 환경에서 Visual Studio Code(이하 VS Code)에 내장된 AI 에이전트를 외부에서 제어하기 위한 병렬 제어 및 메시지 큐 라우팅 도구입니다. 

일반적으로 VS Code 내부에서만 동작하는 AI 에이전트 패널을 macOS의 내장 접근성 기능(Accessibility API)을 활용해 외부 CLI 명령어로 조작할 수 있도록 연결해 줍니다. 이 도구를 통해 개발자는 터미널 환경에서 워크스페이스 단위로 AI 에이전트에게 지시를 내리고 독립적인 대화 세션을 관리할 수 있습니다.

## ✨ 주요 기능

- **병렬 에이전트 제어**: 여러 VS Code 창(워크스페이스)에 띄워진 AI 에이전트들에게 외부 터미널 명령(`agbridge ask`)으로 동시에 프롬프트를 전송할 수 있습니다.
- **메시지 큐(Queue) 라우팅**: 다수의 단기 스크립트나 프로세스가 동시에 입력을 시도하더라도, 중앙 데몬이 대기열을 관리하여 충돌 없이 순차적으로 에이전트에게 전달합니다.
- **상태 보존 세션 관리**: 기본적으로 Stateless한 IDE 패널 UI 환경에 강제로 상태(State)를 부여합니다. 각 프로젝트 디렉토리 내 `.ag-sessions`에 대화 기록과 진행 상태를 캐싱하여 과거 세션을 조회(`session list`)하거나 이어서 대화(`session connect`)할 수 있습니다.
- **워크스페이스 격리**: `--workspace` 옵션을 통해 현재 포커스된 창이 아니더라도, 백그라운드에 있는 특정 프로젝트 창의 AI를 정확히 타겟팅하여 명령을 수행합니다.
- **글로벌 입력 잠금(Global Input Locking)**: CLI가 에이전트 패널에 텍스트를 입력하는 찰나의 순간, 사용자의 키보드 입력이 섞이거나 마우스 포커스가 뺏기는 것을 방지(Race Condition 방지)하여 완벽하게 격리된 타이핑을 보장합니다.

## ⚙️ 구현 원리

이 프로그램은 다음과 같은 기술적 원리를 바탕으로 동작합니다:

1. **macOS Accessibility API (AXUIElement)**  
   Google의 비공식 내부 API나 웹소켓을 역설계하여 통신하는 대신, macOS의 네이티브 접근성 트리를 읽어 화면에 띄워진 VS Code 엘리먼트들(텍스트 에리어, 전송 버튼 등)을 직접 찾아내고 조작(UI Automation)합니다. 이를 통해 웹 API 제약을 우회합니다.
2. **Daemon-Client 아키텍처**  
   사용자가 `agbridge` CLI를 호출하면, 백그라운드에서 상시 구동 중인 데몬(LaunchAgent)에 IPC 혹은 소켓을 통해 명령 페이로드가 전달됩니다. 직접 UI를 조작하는 까다로운 스레드 관리와 큐잉은 모두 데몬이 전담합니다.
3. **DOM 기반 레이아웃 스크래핑**  
   주기적으로 (또는 `info --refresh` 명령 시) IDE 패널의 접근성 트리를 스크래핑하여 활성화된 AI 런타임 환경, 챗봇 모델 정보, 현재 띄워진 세션 패널 이름 등을 추출하고 `registry.json`에 캐싱하여 속도를 극대화합니다.
